# How to Share Your Web Page or Code for Corrections / Cómo enviar tu página o código para corregir errores

Welcome! If you want help reviewing, fixing, or improving your web page or code, you can share it using any of the options below.

---

## 🌎 English Guide

### Option 1: Paste Your Code Directly in the Chat (Quickest)
If your code is relatively short or consists of a few files (e.g., HTML, CSS, JavaScript):
1. **Paste your code:** Use Markdown code blocks with triple backticks so formatting is preserved:
   ````html
   <!DOCTYPE html>
   <html lang="en">
   <head>
       <meta charset="UTF-8">
       <title>My Web Page</title>
       <link rel="stylesheet" href="style.css">
   </head>
   <body>
       <h1>Hello World</h1>
   </body>
   </html>
   ````
2. **Label files clearly:** If you have multiple files, indicate the file name above each code block (e.g., `index.html`, `styles.css`, `script.js`).
3. **Describe the problem:** Let me know what is happening vs. what you expect to happen, any error messages displayed in the browser console, or specific design changes you need.

### Option 2: Share an Online Playground / Live Demo Link
If you would like a live preview of your web page:
1. Paste your code into any free online code editor:
   - **[CodePen](https://codepen.io/)** (Great for frontend HTML/CSS/JS)
   - **[JSFiddle](https://jsfiddle.net/)**
   - **[StackBlitz](https://stackblitz.com/)** or **[CodeSandbox](https://codesandbox.io/)**
   - **[GitHub Gist](https://gist.github.com/)** (Great for sharing files or snippets)
2. Save or publish the pen/fiddle/gist.
3. Share the link in our chat along with details on what needs to be fixed.

### Option 3: Share a GitHub Repository (For Full Projects)
If your project is already organized locally or in a repository:
1. Push your project to a public GitHub repository.
2. Share the repository link (e.g., `https://github.com/username/project-name`).
3. Specify the branch and file(s) that need review or changes.

---

## 🇪🇸 Guía en Español

### Opción 1: Pegar tu código directamente en el chat (La más rápida)
Si tu código es breve o consta de unos pocos archivos (HTML, CSS, JavaScript):
1. **Pega tu código:** Usa bloques de código Markdown con triples comillas invertidas:
   ````html
   <!DOCTYPE html>
   <html lang="es">
   <head>
       <meta charset="UTF-8">
       <title>Mi Página Web</title>
       <link rel="stylesheet" href="style.css">
   </head>
   <body>
       <h1>Hola Mundo</h1>
   </body>
   </html>
   ````
2. **Indica los nombres de archivo:** Si tienes varios archivos, aclara a cuál pertenece cada bloque (por ejemplo, `index.html`, `styles.css`, `script.js`).
3. **Describe el problema:** Cuéntame qué error ocurre, qué mensajes aparecen en la consola del navegador o qué cambios específicos deseas realizar.

### Opción 2: Compartir un enlace a un editor en línea / demo en vivo
Si deseas que se pueda ver la página en funcionamiento en tiempo real:
1. Pega tu código en un editor interactivo en línea:
   - **[CodePen](https://codepen.io/)** (Ideal para HTML/CSS/JS)
   - **[JSFiddle](https://jsfiddle.net/)**
   - **[StackBlitz](https://stackblitz.com/)** o **[CodeSandbox](https://codesandbox.io/)**
   - **[GitHub Gist](https://gist.github.com/)** (Ideal para compartir fragmentos o archivos)
2. Guarda el proyecto y copia el enlace resultante.
3. Pega el enlace aquí en el chat indicando qué correcciones necesitas.

### Opción 3: Compartir un repositorio de GitHub (Para proyectos completos)
Si tu proyecto es más grande o lo tienes en tu computadora:
1. Sube tu código a un repositorio público en GitHub.
2. Comparte el enlace del repositorio (por ejemplo, `https://github.com/usuario/nombre-del-proyecto`).
3. Indica la rama o archivos específicos que requieran revisión.
